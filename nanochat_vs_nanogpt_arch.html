Component NanoGPT (Standard) Nanochat (Optimized) Why Change? Positioning Absolute Learned (WPE) Rotary (RoPE) Better extrapolation to longer contexts; relative distance matters more than absolute position. Normalization LayerNorm (Mean & Var) RMSNorm (Scale only) Simpler, faster, less memory bandwidth (no mean calculation), numerically stable. Attention Standard / Flash 2 Flash Attention 3 Exploits H100 asynchronous data movement (TMA) for higher GPU utilization. Shortcuts Standard Residual (x + f(x)) x0 + Residual Mixing original input (x0) at every layer improves gradient flow in deep networks. Capacity Weights only Value Embeddings Adds "cheap" memory capacity without expensive matrix multiplications. Activation GeLU ReLU² Simpler to compute than GeLU (no exp/tanh) but smoother than ReLU.
